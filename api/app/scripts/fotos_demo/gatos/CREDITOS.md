# Créditos das fotos de gatos da demonstração

Fotos do conjunto **Cat Individual Images** (Tzu-Yuan Lin), publicado em
https://www.kaggle.com/datasets/timost1234/cat-individuals sob a licença **CC BY 4.0**
(https://creativecommons.org/licenses/by/4.0/). As imagens foram feitas em abrigos de Taipei e Nova Taipei.

Foram escolhidos 7 gatos, com 3 fotos cada. Única alteração: redução para no máximo 512 px no lado maior.
