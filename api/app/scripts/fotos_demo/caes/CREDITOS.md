# Créditos das fotos de cães da demonstração

Fotos do conjunto **DogFaceNet** (Mougeot, Li e Jia, "A Deep Learning Approach for Dog Face Verification and
Recognition", 2019), versão `DogFaceNet_224resized`, publicada em https://zenodo.org/records/12578449 sob a licença
**CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/). Foram escolhidos 8 cães, com 3 fotos cada, sem alterações.
